## Quotations, references, and dependencies

Third-party quotations, reproduced snippets, attribution notices, and source
materials retain their existing terms. ROO's grant covers only rights in its
original contributions. Links to books, papers, websites, and repositories do
not imply ownership of those works. The [literature map](research/literature.md)
records sources; it is not a replacement for their license terms.

Rust dependencies, Java jars, PostgreSQL, JDK distributions, container images,
and GitHub Actions retain their upstream licenses. The source release does
not bundle downloaded dependency caches, images, executable binaries, database
data, or credentials. Dependency versions and artifact verification are
recorded in Cargo locks, the existing Java fetch helpers, and
[the Compose pin record](research/roo-compose-pins.json).
